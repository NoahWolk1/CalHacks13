## Tracks

| Track | Challenge | Their examples |
|---|---|---|
| **Payment Agents** | Give an agent a way to pay for things, earn money, or both. Use the Coinbase MCP for Agents and x402 to explore what an agent can do when it can participate in commerce. | An agent that buys tools to finish a job; sells research or a service; hires another agent; or manages the budget for a small business. |
| **Trading Agents** | Agentic trading and portfolio management. Use Coinbase for Agents or the Coinbase Wallet MCP. | A trading strategy template; a portfolio management tool; an agent that tests investment ideas; a skill for monitoring markets and acting on user-defined signals. |

## Prize

For each track, **one** winning team. Each eligible team member receives **$500 USDC** and a call with an Emerging Talent recruiter. Limit one prize per person.

## What you can build

Coinbase for Agents is an MCP that gives an agent a financial account. Start from an existing agent platform or build your own. Skills, templates, integrations and GitHub starter kits are eligible; a standalone app isn't required.

## Getting started

1. Create a Coinbase account (required for prize eligibility).
2. Docs: https://docs.cdp.coinbase.com/ai-agents/overview and https://docs.cdp.coinbase.com/x402/welcome. API key at portal.cdp.coinbase.com.

## Judging

- **Usefulness:** clear problem for an identifiable user.
- **Technical design:** works reliably; explain choices of models, tools, memory, scheduling.
- **Ease of reuse:** another person can install/access it and complete the core task from your instructions.
- **Product feedback:** insightful, actionable feedback on building with Coinbase for Agents.

Not scored: code volume, trading returns, money spent. **Real-money transactions are not required.** Label simulated actions clearly, keep credentials private, don't manage funds for other people.

## What to submit

Choose **one** primary track and include:

- **Project summary:** who it's for, what it does, which agent platform and Coinbase tools it uses.
- **Working example:** short demo plus a repo, installable skill/template, or hosted link with setup instructions.
- **Architecture:** brief explanation or diagram of components, controls, known limitations.
- **Builder feedback:** biggest blocker, how you worked around it, the one missing Coinbase capability you most want.
