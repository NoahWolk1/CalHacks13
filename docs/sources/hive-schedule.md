### Factory Workshop

Shipping with the Factory Droid SDK

"Droid is the coding agent behind Factory's CLI, desktop app, and web platform. With the Droid SDK, you can now put Droid inside your own projects. It plans the steps, uses tools, edits files, and runs commands. You decide when it runs, what it can access, and what it builds.

In this hands-on workshop, we'll go from an empty folder to a working agent-powered app in under an hour. You'll learn how to:
- Install the SDK in TypeScript (npm install @factory/droid-sdk) or Python (pip install droid-sdk) and start your first Droid session.
- Give Droid a task, stream its progress, and handle its results in your app.
- Control what Droid can access: which files, which tools, and which commands.
- Trigger Droid from your own code, like a button, a webhook, a cron job, or a chat message.
- Avoid the common mistakes that cost hackathon teams hours.

We'll end with a live build and a look at what wins our track. Bring a laptop and an idea, or leave with one."

### Hyphenate Workshop

Beyond Agentic Harnesses: Engineering the Autonomous Enterprise

Harnesses made agents capable; the frontier is making them autonomous inside the systems and teams that run a company. We've been doing it in finance, where a single economic event can ripple across a dozen systems and people, and every decision has to stand up to scrutiny long after it's made. We'll take apart how: designing the environment an autonomous system acts in, keeping state across long horizons, orchestrating agents and humans as one team, and building in permissions and traceability from day one. ### SpaceXAI Workshop

Build Your Entire Internship Application Stack in 30 Minutes

What you'll build:

A portfolio website. You'll set up a project in Cursor, have the agent build your site, and deploy it so it's live on the web.
A headshot generator. You'll connect the Grok Imagine API with your API key and turn a casual photo into a professional headshot.
An interview practice tool. Built on the Grok Voice API, it asks you interview questions out loud and responds to your answers. We'll debug it live so you can see how Cursor helps you fix errors fast.
Then we'll show you Grok Bot, an AI assistant that works for you in the background. It has its own computer and browser, connects to apps like Gmail, Google Calendar, Notion and Slack, and can run tasks on a schedule. For your internship search, that means it can:

Find new openings that match the roles you want and keep a running tracker of where you've applied
Check job boards for you every morning and message you when something new shows up
Research a company and its recruiters before you reach out
Draft cover letters and outreach emails for you to review and send
Put interview dates and deadlines on your calendar and remind you before they come up
You don't need experience with AI APIs. If you've written some code before, you can follow along. Install Cursor before you come, and we'll hand out API credits so you can keep building with Grok all weekend.

### Bright Data Workshop - The Unfair Advantage: Live Web Data

The data your project needs often lives on sites that fight automation: Indeed, Glassdoor, Yelp, Booking.com, and Google search results. In 50 minutes, you'll learn to turn public web content into structured data your project can use.

We'll build Intern Intel together: an agent that finds internship listings on Indeed and Glassdoor, combines them into one table, removes duplicates, and helps you filter by role and location. Along the way, you'll see how Bright Data handles web access and extraction, and how your app turns that data into something useful.

We'll build live using Bright Data's MCP server in Claude Code or Cursor, then show how to adapt the workflow to your hackathon idea. You'll leave with a starter repo, including Python, JavaScript, and CLI examples you can reuse.

Code along or just watch. No scraping experience needed.

REQUIREMENTS
To code along:
- Bring a laptop with Claude Code or Cursor installed, signed in, and working.
- Create a Bright Data account and connect its MCP server before the session. Follow the setup guide linked on the event page.
- Have Git installed, or download the starter repo as a ZIP.
- Optional: Python or Node.js to run the standalone examples; tested versions will be listed in the repo.
- Optional: a phone hotspot as a Wi-Fi backup.

### Moss Workshop

Retrieval in 6‑7ms w/ Moss

A hands-on workshop on with Moss, a semantic search library built in Rust and WebAssembly. Participants will build an app that runs low-latency semantic search locally, fast enough to keep up with user input in real time. Topics include creating and loading a vector index, semantic and hybrid (keyword + embedding) search, metadata filtering, and how fast local retrieval applies to RAG pipelines, AI agents, and voice assistants. Participants leave with a starter project they can build on during the hackathon.
